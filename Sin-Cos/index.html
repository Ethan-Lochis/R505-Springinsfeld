sin() & cos()

Effectuez de véritables calculs trigonométriques directement en CSS pour positionner des éléments en cercle, créer des orbites et des trajectoires ondulatoires sans JavaScript.

📖 1. Explication

Positionner des éléments selon une disposition circulaire ou orbitale (par exemple un menu radial, les repères d'une montre ou une animation en arc de cercle) imposait jusqu'ici de recourir à JavaScript avec Math.sin() et Math.cos(), ou d'utiliser des astuces CSS rigides à base de rotations superposées (transform: rotate(...) translate(...) rotate(...)).

Les fonctions mathématiques CSS sin() et cos() permettent de calculer directement les coordonnées cartésiennes d'un point sur le cercle trigonométrique à partir d'un angle (en deg, rad ou turn) et d'un rayon : x = cos(angle) * r et y = sin(angle) * r.

Couplées à calc() et aux variables CSS personnalisées, elles ouvrent la voie à des interfaces géométriques dynamiques, des menus radiaux réactifs et des animations harmoniques ultra-légères.

💻 2. Syntaxe

La formule universelle pour placer un élément sur une orbite de rayon R selon un angle θ :

CSS trigonometry.css 
:root {
  --radius: 120px;
}

/* Positionnement sur un cercle par trigonométrie */
.orbit-item {
  --x: calc(cos(var(--angle)) * var(--radius));
  --y: calc(sin(var(--angle)) * var(--radius));

  transform: translate(var(--x), var(--y));
}

/* Répartition des enfants à des angles spécifiques */
.item-1 { --angle: 0deg; }
.item-2 { --angle: 90deg; }
.item-3 { --angle: 180deg; }
.item-4 { --angle: 270deg; }

/* Autres fonctions disponibles : tan(), asin(), acos(), atan(), atan2() */

🛡️ 5. Note sur le Fallback & Stratégies de Repli

Comment garantir la robustesse de vos animations mathématiques ?

  • Stratégie historique avec rotations cumulées :
    Pour les navigateurs plus anciens, le positionnement radial s'effectuait en faisant tourner l'élément, en le déplaçant sur l'axe X puis en annulant la rotation du texte : 
    .legacy-orbit {
  /* Repli classique sans trigonométrie */
  transform: rotate(var(--angle)) translate(var(--radius)) rotate(calc(-1 * var(--angle)));
}
  • Détection avec @supports (transform: translate(cos(0deg), sin(0deg))) :
    Permet d'activer la syntaxe vectorielle pure uniquement si le moteur d'affichage supporte les fonctions trigonométriques : 
    @supports (top: calc(sin(1deg) * 1px)) {
  .orbit-item {
    transform: translate(calc(cos(var(--a)) * 100px), calc(sin(var(--a)) * 100px));
  }
}
