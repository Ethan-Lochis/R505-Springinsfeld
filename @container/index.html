@container

Adapte le style d'un composant en fonction des dimensions ou du style de son conteneur direct, et non plus de l'écran global.

📖 1. Explication

Pendant des années, le design responsive reposait uniquement sur les Media Queries (@media), qui interrogent les dimensions globales du viewport (fenêtre du navigateur). Cette approche posait un problème récurrent pour les architectures modulaires de composants : une même carte doit souvent s'afficher différemment selon qu'elle se trouve dans une barre latérale étroite (300px) ou au centre d'une page large (800px).

La règle @container (Container Queries) résout ce défi en permettant à un élément d'adapter son apparence directement à l'espace alloué par son conteneur parent (défini via container-type).

Les composants deviennent ainsi véritablement autonomes, portables et réutilisables n'importe où dans la mise en page sans dépendre de la largeur totale de l'écran.

💻 2. Syntaxe

L'utilisation se fait en deux étapes indispensables :

CSS container-queries.css 
/* Étape 1 : Définir le parent comme contexte de conteneur */
.card-container {
  container-type: inline-size; /* surveille la largeur */
  container-name: sidebar-card; /* optionnel mais recommandé */
}

/* Étape 2 : Appliquer les styles conditionnels selon le conteneur */
@container (min-width: 480px) {
  .card {
    display: grid;
    grid-template-columns: 150px 1fr;
  }
}

/* Variante : Style Queries (requête sur une propriété ou variable) */
@container style(--theme: dark) {
  .card {
    background-color: #1e1e1e;
    color: #ffffff;
  }
}

🛡️ 5. Note sur le Fallback & Stratégies de Repli

Comment sécuriser vos interfaces pour les navigateurs non compatibles ?

  • Approche Mobile-First par défaut :
    Concevez toujours le composant dans sa version la plus compacte ou flexible par défaut (sans container queries). Les règles @container viennent enrichir la mise en page uniquement lorsque le navigateur les comprend.
  • Détection avec @supports (container-type: inline-size) :
    Vous pouvez séparer vos styles ou appliquer des media queries classiques de repli si le support manque : 
    /* Repli Media Query standard si @container n'est pas supporté */
@media (min-width: 768px) {
  .card { flex-direction: row; }
}

/* Amélioration avec les vraies dimensions de conteneur */
@supports (container-type: inline-size) {
  @container (min-width: 480px) {
    .card { flex-direction: row; }
  }
}
  • Polyfill officiel :
    L'équipe Google Chrome Labs maintient un polyfill officiel léger (container-query-polyfill) qui analyse le DOM avec ResizeObserver et applique les classes appropriées si le navigateur ne gère pas nativement @container.
