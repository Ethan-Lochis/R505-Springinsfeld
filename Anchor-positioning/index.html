CSS Anchor Positioning

Ancrez et alignez des éléments flottants (infobulles, popovers, menus volants, badges) sur n'importe quel élément cible de la page sans une seule ligne de JavaScript.

📖 1. Explication

Pendant des décennies, positionner avec précision une infobulle (tooltip), un menu déroulant ou un menu contextuel à côté d'un élément déclencheur représentait un casse-tête majeur en CSS. Si l'élément parent utilisait un overflow: hidden ou clip-path, l'élément flottant était immédiatement tronqué, contraignant les développeurs à recourir à de volumineuses bibliothèques JavaScript (telles que Popper.js ou Floating UI) pour écouter le défilement et calculer les coordonnées avec getBoundingClientRect().

La spécification CSS Anchor Positioning (introduite en 2024) révolutionne cela en permettant d'associer déclarativement un élément flottant (positionné en absolute ou fixed) à un élément d'ancrage nommé via la propriété anchor-name.

Grâce aux nouvelles propriétés position-anchor, position-area ou à la fonction anchor(), le navigateur calcule et recalcule en temps réel l'alignement directement au niveau du compositeur, avec des performances natives optimales à 60 ou 120 images par seconde.

💻 2. Syntaxe

L'ancrage CSS repose sur la définition d'un nom d'ancre (variable débutant par deux tirets --) puis sur son rattachement :

CSS anchor-positioning-syntax.css 
/* 1. Déclarer l'élément cible comme point d'ancrage */
.btn-trigger {
  anchor-name: --btn-anchor;
}

/* 2. Méthode moderne simplifiée : position-area */
.tooltip {
  position: absolute;
  position-anchor: --btn-anchor;
  position-area: top center; /* Positionne au-dessus et centré */
  margin-bottom: 8px;
}

/* 3. Méthode granulaire avec la fonction anchor() */
.custom-badge {
  position: fixed;
  top: anchor(--btn-anchor bottom);
  left: anchor(--btn-anchor center);
  transform: translateX(-50%);
}

/* 4. Gestion intelligente du débordement d'écran (Flip) */
.dropdown-menu {
  position: absolute;
  position-anchor: --btn-anchor;
  position-area: bottom span-all;
  position-try-fallbacks: flip-block, flip-inline;
}

🛡️ 5. Note sur le Fallback & Stratégies de Repli

Comment intégrer sereinement CSS Anchor Positioning dans un projet tout en garantissant une expérience irréprochable sur les navigateurs plus anciens ?

  • 1. Détection des fonctionnalités avec @supports :
    Conditionnez l'ancrage CSS moderne tout en fournissant un positionnement traditionnel (position relative/absolute basique) pour les anciens navigateurs : 
    /* Positionnement standard de repli */
.tooltip {
  position: absolute;
  top: 100%;
  left: 50%;
  transform: translateX(-50%);
}

/* Amélioration progressive avec Anchor Positioning */
@supports (anchor-name: --test) {
  .tooltip {
    position-anchor: --btn-anchor;
    position-area: top center;
    transform: none;
  }
}
  • 2. Le Polyfill officiel CSS Anchor Positioning :
    Pour supporter Safari et Firefox de façon transparente sans modifier une seule ligne de votre CSS, vous pouvez inclure le polyfill certifié : 
    <!-- Polyfill officiel OddBird via CDN -->
<script type="module" src="https://unpkg.com/@oddbird/css-anchor-positioning/dist/css-anchor-positioning-fn.js"></script>
  • 3. Fallback JavaScript conditionnel :
    Si le navigateur ne supporte pas CSS.supports('anchor-name', '--a'), chargez dynamiquement Floating UI ou un positionnement JS pour les éléments critiques nécessitant un évitement des collisions d'écran.
