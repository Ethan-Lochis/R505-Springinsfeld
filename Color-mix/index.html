color-mix()

Mélangez deux couleurs dans un espace colorimétrique spécifié (srgb, oklch, hsl) avec des ratios personnalisés sans préprocesseur ni script.

📖 1. Explication

Avant l'arrivée de color-mix(), générer des nuances dérivées (états hover, teintes éclaircies, ombrages ou modes semi-transparents) nécessitait soit de déclarer manuellement des dizaines de variables hexadécimales, soit de passer par des préprocesseurs tels que Sass (lighten(), darken()) ou des scripts JavaScript.

La fonction CSS native color-mix() permet d'effectuer des calculs et mélanges de couleurs dynamiques directement dans le navigateur. Elle accepte deux couleurs, leurs pourcentages respectifs et un espace d'interpolation (comme in srgb, in hsl ou le très moderne et uniforme in oklch).

Cette avancée simplifie considérablement la création de Design Systems et thèmes clair/sombre, en permettant de calculer toutes les nuances à partir d'une seule couleur primaire (ex: color-mix(in srgb, var(--primary) 70%, white)).

💻 2. Syntaxe

La fonction s'articule autour de l'espace de couleur cible et des proportions :

CSS color-mix-examples.css 
/* 1. Éclaircir une couleur primaire (70% primaire + 30% blanc) */
.card-light {
  background: color-mix(in srgb, var(--primary) 70%, white);
}

/* 2. Assombrir une couleur (ajouter du noir) */
.card-border {
  border-color: color-mix(in srgb, var(--primary) 85%, black);
}

/* 3. Rendre une couleur semi-transparente sans modifier son opacité générale */
.badge-transparent {
  background: color-mix(in srgb, var(--primary) 20%, transparent);
}

/* 4. Utilisation de l'espace perceptuel moderne OKLCH (transition sans zone terne) */
.vibrant-fusion {
  background: color-mix(in oklch, #3b82f6 50%, #ef4444);
}

🛡️ 5. Note sur le Fallback & Stratégies de Repli

Comment intégrer sereinement color-mix() dans un projet de production ?

  • Cascade CSS par déclaration préalable :
    Fournissez simplement une valeur statique (hexadécimale ou hsl) juste avant la déclaration utilisant color-mix(). Les navigateurs anciens ignoreront la seconde ligne sans provoquer d'erreur : 
    .button {
  /* 1. Repli pour vieux navigateurs */
  background-color: #818cf8;
  /* 2. Rendu dynamique moderne */
  background-color: color-mix(in srgb, var(--primary) 70%, white);
}
  • Détection via la règle @supports (color: color-mix(...)) :
    Permet de conditionner l'activation de thèmes entièrement dynamiques : 
    @supports (background-color: color-mix(in srgb, red, blue)) {
  :root {
    --primary-hover: color-mix(in srgb, var(--primary) 85%, black);
    --primary-light: color-mix(in srgb, var(--primary) 20%, transparent);
  }
}
